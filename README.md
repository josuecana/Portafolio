En este repositorio contengo códigos hechos en mi curso por mí mismo, usando herramientas enseñadas como elementos finitos, métodos de integración de Monte Carlo, cadenas de Markov y solución de diversas EDP de diversas ecuaciones diferenciales.

También tengo códigos del curso de probabilidad y estadística, haciendo análisis estadísticos junto a compañeros, aplicando teoría de probabilidad y estadística aprendidas del libro «Probabilidad y estadística para ciencias químico-biológicas».

Códigos del curso Métodos Computacionales, usando herramientas como derivación numérica, interpolación, integración Simpson, Runge-Kutta y métodos para hallar raíces como Newton-Raphson.
